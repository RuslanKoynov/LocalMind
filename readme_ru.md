# LocalMind — Локальный ИИ для работы с базой знаний

**LocalMind** — это автономный инструмент на базе ИИ, который позволяет загружать локальные документы (PDF, DOCX, TXT, Markdown), индексировать их и задавать вопросы на естественном языке. Вся обработка происходит **полностью офлайн**, данные не передаются в облако.

---

## 📦 Установка

### Требования
- ОС: Windows, macOS или Linux  
- Python 3.10 или новее  
- [Ollama](https://ollama.com/) — для запуска большой языковой модели (LLM)  
- Минимум 4 ГБ ОЗУ (рекомендуется 8 ГБ+ для более крупных моделей)

### Шаги

1. **Установите Python** (если еще не установлен):  
   [https://www.python.org/downloads/](https://www.python.org/downloads/)

2. **Установите Ollama**:  
   Следуйте инструкциям на [https://ollama.com/](https://ollama.com/)

3. **Скачайте проект** (или клонируйте репозиторий):
   ```bash
   git clone https://github.com/RuslanKoynov/LocalMind.git
   cd localmind
   ```

4. **Установите зависимости Python**:
   ```bash
   pip install streamlit chromadb sentence-transformers PyPDF2 python-docx networkx
   ```

5. **Загрузите языковую модель в Ollama** (выберите одну):

   Для лучшей поддержки русского языка:
   ```bash
   ollama pull qwen2.5:1.5b
   ```

   Или более легкий вариант (хорошо работает на слабых ПК):
   ```bash
   ollama pull phi3:mini
   ```

## ⚙️ Конфигурация

### Дополнительные настройки

Чтобы использовать другую LLM, отредактируйте файл **`app.py`**:

1. Найдите функцию `ask_ollama(...)`
2. Измените параметр `model` по умолчанию:

   ```python
   def ask_ollama(prompt: str, temperature: float = 0.2, model: str = "phi3:mini") -> str:
   ```

   Замените его на имя модели из вашего списка `ollama list`.

### Директории проекта

- `documents/` — хранит оригиналы загруженных файлов (создается автоматически)  
- `chroma_db/` — локальная векторная база знаний (создается автоматически)  
- `knowledge_graph.pkl` — локальный граф знаний (создается автоматически)

> Все данные остаются на вашем устройстве и **никогда не покидают вашу систему**.

## 🚀 Использование

### 1. Запуск приложения

В терминале перейдите в папку проекта и выполните:

```bash
streamlit run app.py
```

### 2. Загрузка документов

- Поддерживаемые форматы: `.txt`, `.md`, `.pdf`, `.docx`  
- Можно загружать **один или несколько файлов одновременно**  
- Файлы автоматически индексируются в **Векторную БД** и **Граф Знаний** (может занять несколько секунд)

### 3. Задайте вопрос

- Введите ваш вопрос в поле чата  
- ИИ использует **Гибридный RAG (Векторный поиск + Граф)**:
    - **Векторный поиск**: находит наиболее подходящие фрагменты текста.
    - **Расширение через граф**: находит связанные сущности и связи для более широкого контекста.
- ИИ возвращает ответ **со ссылками на источники**.

### 4. Примеры запросов

- «Какие системные требования для установки?»  
- «Кто автор документа ‘Руководство пользователя’?»  
- «Перечисли шаги по настройке модуля X.»  
- «Кто такая Татьяна Ларина?» (если вы загрузили *Евгения Онегина*)

### 5. Настройка температуры ИИ

Чем выше значение, тем больше «фантазии» (креативности) будет использовать ИИ в ответах. Для поиска по документам обычно достаточно значения 0.3.

## 🔐 Приватность и Безопасность

- Все вычисления происходят **локально на вашем компьютере**  
- Данные не передаются через интернет (после первоначальной загрузки модели)  
- Векторная база данных и граф знаний хранятся на вашем локальном диске  
- Безопасно для использования в корпоративных средах со строгими политиками данных

## 🛠 Решение проблем

| Проблема | Решение |
|------|----------|
| «Ошибка генерации» | Убедитесь, что Ollama запущена и модель загружена (`ollama list`) |
| PDF не загружаются | Убедитесь, что PDF содержит текстовый слой (не является сканом изображения) |
| Медленный первый запуск | Модель эмбеддингов скачивается при первом запуске (требуется интернет один раз) |
| Приложение не запускается | Проверьте, установлены ли все зависимости (`pip list`) |
