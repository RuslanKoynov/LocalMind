# LocalMind — Локальный ИИ ассистент для работы с базами знаний (Быстрый старт)

**LocalMind** — это автономный инструмент на основе искусственного интеллекта, позволяющий загружать локальные документы (PDF, DOCX, TXT, Markdown), индексировать их и задавать вопросы на естественном языке. Весь процесс происходит **оффлайн**, без передачи данных в облако.

---

## 📦 Установка

### Требования
- ОС: Windows, macOS или Linux  
- Python 3.10 или новее  
- [Ollama](https://ollama.com/) — для запуска языковой модели (LLM)  
- Минимум 4 ГБ оперативной памяти (рекомендуется 8 ГБ+ для больших моделей)

### Шаги

1. **Скачайте проект** (или клонируйте репозиторий):
   ```bash
   git clone https://github.com/RuslanKoynov/LocalMind.git
   cd localmind
   ```

2. **Установите Ollama**:  
   Следуйте инструкциям на [https://ollama.com/](https://ollama.com/)

3. **Установите зависимости Python**:
   ```bash
   pip install streamlit chromadb sentence-transformers PyPDF2 python-docx networkx torchvision requests
   ```

4. **Загрузите языковую модель в Ollama** (выберите одну):

   Для лучшей поддержки русского языка:
   ```bash
   ollama pull qwen2.5:1.5b
   ```

   Либо более лёгкий вариант (работает и на слабых ПК):
   ```bash
   ollama pull phi3:mini
   ```

## 🚀 Использование

### 1. Запуск приложения

В терминале перейдите в папку проекта и выполните:

```bash
streamlit run app.py
```

Приложение откроется в вашем браузере автоматически.

### 2. Загрузка документов

- Поддерживаемые форматы: `.txt`, `.md`, `.pdf`, `.docx`
- Можно загружать **один или несколько файлов одновременно**
- После загрузки файлы индексируются автоматически в **Векторную БД** и **Граф Знаний**.

### 3. Задание вопросов

- Введите вопрос в поле чата
- ИИ использует **Гибридный RAG (Векторный поиск + Граф)**, чтобы найти наиболее подходящую информацию и связанные связи.
- ИИ дает ответ **с указанием источников**.

### 4. Примеры вопросов

- «Какие требования к установке системы?»
- «Кто автор документа "Руководство пользователя"?»
- «Кто такая Татьяна Ларина?» (если загружен «Евгений Онегин»)

## 🔐 Приватность и безопасность

- Все вычисления происходят **локально на вашем компьютере**
- Данные не передаются в интернет (после первоначальной загрузки модели)
- Векторная база и граф знаний хранятся на вашем диске

---

## 🛠 Устранение неполадок

| Проблема | Решение |
|--------|--------|
| «Ошибка генерации» | Убедитесь, что Ollama запущен и модель загружена (`ollama list`) |
| Не загружаются PDF | Убедитесь, что файл не сканированный (требуется текстовый PDF) |
| Долгая загрузка | При первом запуске модель эмбеддингов скачивается (требуется интернет) |
